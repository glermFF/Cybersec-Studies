 O principal proposito da criptografia é tornar uma mensagem segura e encoberta contra agentes maliciosos ou curiosos que querem meter o nariz onde não deve. A ideia da criptografia não é de hoje em dia, tendo registros históricos de pessoas usando essa forma de esconder informações desde a roma antiga. Tanto que existe a Cifra de Cesar a qual veremos um pouco aqui.

A necessidade da criptografia para assegurar arquivos, mensagens, dados, sistemas, se torna crucial atualmente por tudo rodar por meio de sistemas informatizados e digitalizados.

### Simétrica

A Criptografia Simétrica é uma maneira simples ao codificar um dado é usada uma única chave para decodificar este dado. Não é muito recomendado pelo fato de que se a chave for descoberta/encontrada o dado não está mais seguro. Também, não é bom usar uma única chave para vários dados.

A chave decodificadora é chamada de chave pública.

### Hash

Message Digest 5 (MD5) is a cryptographic hash function that takes any input and produces a 128-bit hexadecimal number. The output of an MD5 hash function is called a digest. MD5 digests are often used to verify the integrity of files or data; however, MD5 is no longer considered secure and should not be used for sensitive applications.

### SSH

Secure Shell (SSH) refers to a cryptographic network protocol used in secure communication between devices. SSH encrypts data using cryptographic algorithms, such as Advanced Encryption System (AES) and is often used when logging in remotely to a computer or server.
