### Redes Wireless

- Evite usar o a criptografia em WEP, é a mais fácil de ser quebrada;
- Recomendado usar criptografia WPA/WPA2 combinado de uma senha complexa (maiúsculas, minusculas, caracteres especiais);
- Não é recomendado usar WPS combinado com sua rede WPA/WPA2 pois abre uma brecha para ataques de brute force;

Acessando as configurações do roteador podemos alterar para as configurações que vou deixar recomendadas:

- Habilite o WPA2;
- Coloque uma senha de pelo menos 12 caracteres (minimo é 8, mas quanto mais, mais forte);
- Desabilite o WPS;
- (Opcional) Deixar sua rede invisível;
